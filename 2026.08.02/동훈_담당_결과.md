# 동훈 담당 결과 — 다른 예측 모델(B) 구축 및 A모델 비교/블렌딩

작성일: 2026-08-02
담당: 권동훈 (B모델 구축, A모델과의 비교/블렌딩 분석)

---

## 0. 배경

현윤(A모델, `model_A/`)과는 별도로, 서로 다른 오차 패턴을 갖는 B모델을 구축하고
앙상블 가능성을 검증하는 것이 목표. B모델은 `src/train_baseline.py`(v3~v30) 기반.

## 2. 세부 결과

### 2-1. A모델 대비 상관관계·차이 (2025 test 기간, 정답 없음 — 다양성 확인용)

| 지표 | B(v25) | B(v29, 850hPa 추가 후) |
|---|---|---|
| 상관계수(그룹1/2/3) | 0.9802 / 0.9793 / 0.9735 | 0.9814 / 0.9812 / 0.9751 |
| 평균 예측값 차이 | 5.5~6.8% | 5.4~6.3% |

→ 850hPa 피처를 추가하니 오히려 A모델과 **더 비슷해짐** (같은 실제 물리 신호에 수렴한 것으로 해석).
A모델 내부 구성요소(lgb/cat/xgb)끼리도 상관 0.994 이상 — "어떤 A 구성요소를 쓰든 다양성은 비슷".

### 2-2. 실제 2024 라벨 기준 정확도 비교 (핵심 결과)

| 모델 | Score | 1-NMAE | FICR |
|---|---|---|---|
| A_lgb | 0.6384 | 0.8802 | 0.3966 |
| A_blend | 0.6381 | 0.8803 | 0.3958 |
| **B(v29 방식, FICR조정)** | **0.6416** | 0.8756 | **0.4077** |
| **최적 블렌딩(A:B=50:50)** | **0.6448** | 0.8808 | 0.4088 |

- B가 A를 근소 우위 (1-NMAE는 A가 낫지만 FICR에서 B가 역전 — FICR 후처리 기법의 효과)
- 오차 상관계수: 그룹1 0.86, 그룹2 0.83, 그룹3 0.76 (1.0보다 확실히 낮아 서로 다른 실수를 하고 있음)
- 그룹별 승부: 그룹1·3은 B우세, 그룹2는 A우세로 갈림
- 고발전(상위25%, 대체로 고풍속) 구간 승부도 그룹마다 갈림

### 2-3. ⚠️ 실제 리더보드 검증 결과 — 재현 실패

| | 실제 리더보드 |
|---|---|
| A 단독 | **0.63625** |
| B 단독(v29) | 0.62204 |
| A:B=50:50 블렌딩 | 0.63287 |

**2024 fold에서 검증된 블렌딩 우위(0.6448 > 0.6381, 0.6416)가 실제 2025 test에서는 재현되지 않음**
(블렌딩 0.63287 < A단독 0.63625). 단일 fold 최적화의 일반화 한계로 판단.

→ **현재 팀 최고 기록은 A 단독(0.63625)으로 유지.**

## 3. B모델 자체 개선 이력 (feature engineering)

| 버전 | 내용 | 실제 리더보드 |
|---|---|---|
| v11 | MAE objective + 시드 앙상블 | 0.6146 |
| v23 | FICR 직접 최적화(후처리) | 0.6156 |
| v25 | FICR 조정 수축(shrinkage 0.5) | **0.6165** |
| **v29** | **850hPa 풍속/풍향/윈드시어** | **0.6220** |
| v30 | 착빙 위험 플래그 (시도) | 기각 (importance=0, backtest 하락) |

12개 이상의 피처 엔지니어링 시도 중 실제 개선으로 이어진 건 v25(후처리)와 v29(850hPa)뿐.
나머지(파워커브, SCADA 물리피처, 상호작용항, 격자분산, 착빙플래그 등)는 트리 모델이 이미
학습 가능한 정보이거나 학습데이터 대비 조건이 너무 좁아 기각됨.

## 4. 부가 조사 — 실제 기상 이벤트 대조

- 태풍 힌남노(2022-09-04~06), 카눈(2023-08-10)이 태백산 국립공원 통제 등으로 직접 영향을
  준 것은 뉴스로 확인되나, 실제 발전 라벨 대조 결과 **컷아웃 수준까지는 못 미치는 평범한 수준**
- **2024-01-18~24 혹한기**: 바람은 정상(평균 4.8m/s)인데 발전량 50%+ 시간대가 거의 0 —
  착빙 강제정지로 추정되는 패턴 확인 (다만 학습데이터 전체 통계로는 신호가 약해 피처화는 실패)
- 2024-02-19~29(9~10일), 2024-08-10~21(11일) 초장기 무발전 구간도 발견 — 각각 착빙/저풍속
  혼재, 순수 저풍속으로 원인이 다름을 확인
- 70일 주기 정기정비 패턴(다른 대회 사례 참고 검증) — **기각** (우리 데이터에는 해당 패턴 없음)

## 5. 결론 및 다음 제안

1. **B모델 단독으로는 A모델을 못 넘음** (0.6220 vs 0.63625)
2. **블렌딩도 아직 A모델을 못 넘음** — 향후 재시도한다면 단일 fold가 아니라 여러 시기에 걸친
   블렌딩 비율 검증(우리 backtest.py 다중윈도우 인프라 활용)이 필요해 보임
3. B모델에서 실증된 두 가지 기법(FICR 겨냥 후처리 수축, 850hPa 상층풍)은 A모델에도 적용
   가능한 아이디어일 수 있어 현윤과 공유할 가치 있음
4. LSTM은 현재 데이터 규모로는 트리를 못 이김 — 추가 투자 우선순위 낮음

**현재 팀 최종 제출 후보: A모델 단독 (0.63625)**

## 6. A모델 기반 추가 실험 (model_A_dh, 동훈추가분)

- [x] 후류(wake) 가설 - 위경도 계산(방위각 115도)이 forensics 최악구간과 정확히
      일치해 유망해 보였으나, 실제 SCADA 풍속(13,532시간)으로 검증한 결과 반대
      방향(그룹2가 오히려 6.4% 강함)으로 명백히 기각됨. fold A 개선은 작은 표본의
      우연한 상관(과적합)이었던 것으로 결론. 최종 미채택.
- [x] 2025년이 학습범위(2022-24)를 벗어나는지 점검 → 풍속·기압·습도 등 핵심 지표
      전부 범위 안(외삽 위험 없음), 기온만 0.21%(18시간) 미세 초과하나 무시 가능한
      수준. 다만 "범위 안이지만 희소한 고풍속 구간"의 정확도 문제는 별개로 남아있음
      (analyze_over8pct_forensics.py의 group3 고풍속 단조증가 패턴과 연결됨)
- [x] FICR 겨냥 후처리(전그룹, 수축50%) 시도 → fold B 최대개선(+0.0055) 확인했으나
      실제 리더보드에서 오히려 최저(0.63166, 원본 대비 -0.0046). 원인: fold 검증(45일
      calib)과 실제 제출(g1_calib 재사용, 365일 calib) 로직 불일치 - 검증 안 된
      버전이 제출됨. 850hPa 단독 확정판 유지.
- [x] **새로운 최종 확정판**: 그룹1은 850hPa 단독(원본) 유지, 그룹2·3만 편향보정 +
      착빙형 이상치 완전제외 + 태풍형 다운웨이트(가중치0.3) 적용
      → 실제 리더보드 0.63802 (원본 A모델 0.63625 대비 +0.00177, 최초로 원본 초과)
- [x] recency 가중치 시도 - group2(wtg07 만성패턴) 기각, group1(wtg05 회복패턴)도
      fold에선 미세개선(+0.0004~0.0011)이었으나 실제 리더보드는 오히려 하락
      (-0.0006, 0.64129->0.64069). wtg05가 회복 중이라는 진단 자체는 맞았을
      수 있으나, 회복 속도/패턴을 연도별 가중치로 단순화하는 방식 자체가
      부정확했던 것으로 추정. 완전 기각, recency 가중치 트랙 종료.
- [x] 연직 대기불안정도(t_instability) 피처 시도 → fold 소폭개선(+0.0011~0.0014)
      이었으나 실제 리더보드는 오히려 하락(-0.00069). "fold 개선폭 <0.005는
      신뢰불가"라는 오늘의 경험법칙이 다시 확인됨. 기각.
