## 1. 모델 구조

그룹별(kpx_group_1/2/3) 독립 LightGBM 회귀 모델 3개. 근거:

- `docs/eda_report.md` §2: 세 그룹의 풍황·터빈 제조사·라벨 이력 길이가 다름 → PLAN.md §1.3 "3개의 관련되었지만 별개인 문제로 취급"과 일치. 그룹 공유 모델 대신 그룹별 독립 모델 선택.
- 타겟은 `실적kWh / 설비용량kWh`(capacity fraction)로 정규화해서 학습 — PLAN.md §1.2 NMAE 정의(분모가 고정 설비용량)와 맞춤. 그룹 간 손실 스케일이 자연히 비교 가능해짐.

## 3. CV 방법 — 근거

- **시간순 확장창(expanding-window) 4-fold**, 랜덤 셔플 절대 안 함 (`src/cv.py`) — PLAN.md §1.3 "trustworthy offline CV, leaderboard probing 안 됨"에 대응. 각 fold는 과거 데이터만으로 미래를 예측(실제 대회 조건과 동일 — test 기간엔 과거 실적 못 씀).
- **평가 시 10% 미적격 시간 마스킹** (`src/metrics.py`) — PLAN.md §1.2 "Scoring scope"와 `eda_report.md` §3(전체 시간의 39~46%가 채점 제외)을 그대로 반영. 마스킹 없이 CV를 보면 실제 리더보드 점수와 괴리가 생김.

### CV 결과 (macro, 적격시간만)

| 그룹 | NMAE | 1-NMAE |
|---|---:|---:|
| kpx_group_1 | 0.1382 | 0.8618 |
| kpx_group_2 | 0.1361 | 0.8639 |
| kpx_group_3 | 0.1579 | 0.8421 |
| **macro** | **0.1440** | **0.8560** |

그룹3이 제일 낮음 — `eda_report.md` §3("그룹3은 저CF 꼬리가 더 두꺼움, 라벨 이력 1년 적음")과 방향이 일치. 이 총점은 **FICR 없이 NMAE 성분만**(1-NMAE); 실제 대회 스코어는 `0.5×(1-NMAE) + 0.5×FICR`라서 이 숫자를 그대로 리더보드 예상치로 쓰면 안 됨(§4 참고).

## 4. 이번 제출에 반영 안 된 것 (알고 하는 단순화)

- **FICR 미구현.** PLAN.md §1.2에 명시된 대로 정산단가 구간표가 평가페이지 이미지라서 텍스트 추출 실패 — 브라우저로 직접 확인 필요(Open Q6, 미해결). 지금은 NMAE만 최적화.
- **그리드 축소 방식 그룹별 CV 선택 안 함.** §Open Q7이 원래 권장한 대로 mean/nearest/idw 세 방법을 다 피처로 넣고 CV가 그룹별로 고르게 하는 대신, 이번엔 mean 하나로 통일(단순화, 성능 손실은 작을 것으로 추정되나 미검증).
- **SCADA 기반 물리 파워커브 피처 없음.** PLAN.md §1.1/M2가 원래 제안한 "SCADA로 피팅한 파워커브를 물리 기반 피처/블렌드 성분으로" 아직 안 만듦 — test 기간엔 SCADA가 없어서 모델 입력 자체는 아니지만, train 파워커브를 예보 풍속에 적용하는 보조 피처는 다음 이터레이션 후보.
- **앙상블 없음.** LightGBM 단일 모델. PLAN.md §1.5 우선순위 4번(GBM 변종 블렌딩)은 아직.
