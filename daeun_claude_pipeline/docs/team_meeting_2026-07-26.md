| 회차 | 구성 | 1-NMAE | FICR | **Total** | 비고 |
|---|---|---:|---:|---:|---|

## 1. 현재까지의 접근 방식

이번 대회는 과거 발전량을 이용한 시계열 예측이 아니라, **하루 전 기상예보(LDAPS, GFS)만으로 발전량을 예측하는 정형 데이터 회귀 문제**. 테스트 기간(2025년 전체)엔 실적/SCADA가 전혀 없어서 자기회귀가 불가능.

**평가지표** (2026-07-26 평가페이지에서 직접 확인 — 이미지로만 렌더링돼서 base64 디코딩으로 확보):

```
Total = 0.5 × (1-NMAE) + 0.5 × FICR
NMAE = mean(|예측-실적|/설비용량)               — 적격시간만(실적≥설비용량10%)
FICR = 획득정산금/이론상최대정산금
  시간별 정산단가: NMAE≤6% → 4원/kWh, 6~8% → 3원/kWh, 8%초과 → 0원  ← 계단형 보상구조
```

**EDA 핵심 발견** (`docs/eda_report.md`):
- 풍속이 압도적 1순위 변수(Pearson 0.727), 풍향·기온·시간대도 유의미한 2차 신호
- 풍속-발전량은 강한 비선형(시그모이드형 파워커브, cut-in~rated 구간에서 분산 큰 "고원")
- 전체 시간의 39~46%가 적격기준(10%) 미달로 아예 채점 제외 — 지배적 제약조건
- 그룹1/2(VESTAS)와 그룹3(UNISON)은 제조사·좌표·라벨이력(그룹3은 1년 적음)이 다 다름 → 그룹별 독립 모델로 설계

**LightGBM을 기본 모델로 선정한 이유:**
- 정형(Tabular) 데이터에 강함
- 비선형 관계를 자동으로 학습 가능 (별도 파워커브 수식 없이도 풍속→발전량의 시그모이드 형태를 트리 분기로 근사)
- 결측치 처리에 강함
- 실험 반복 비용이 낮음(학습 수초~수십초, 이번 세션에서 objective/그리드축소/보정 여러 조합을 몇 분 안에 A/B 가능했던 이유)

**현재까지 LightGBM + L1 Objective(`regression_l1`)가 가장 안정적** — 대회 지표가 정확히 MAE 기반인데 처음엔 L2(제곱오차)를 최적화하던 미스매치를 바로잡은 것. 실측으로 확정된 유일한 순수 개선(3차 제출).

## 2. 수행한 주요 실험과 결과

### 2.1 Grid Aggregation (기상 격자 → 풍력단지 위치 변환) 최적화

mean / nearest / IDW 3가지 방식 비교. EDA 단계에서 그룹별로 상관관계가 다르게 나왔지만(그룹1은 mean이 우세, 그룹2/3은 nearest가 우세), 이를 반영해 그룹별 최적 방식을 적용한 4차 제출에서 **실제 리더보드 성능은 오히려 소폭 하락**(0.6059→0.6044). 그래서 현재는 다시 mean 방식으로 통일.

### 2.2 Calibration (Isotonic)

모델 출력을 실측에 맞춰 보정. 다중 폴드 평균 CV에서는 개선 신호가 뚜렷했지만(macro total 0.575→0.585 예측), **실제 제출(2차)에서는 성능이 하락**(0.6031→0.5954). 원인 분석: isotonic이 그룹별로 부호가 정반대로 튀는 걸 발견(그룹1은 크게 개선, 그룹2/3은 악화) — 다중 폴드 평균이 이 불안정성을 가림. 더 엄격한 단일 last-block holdout으로 재검증해도 마찬가지로 나쁘게 나옴. 자유도가 높은 비모수적 방법이라 과적합 가능성 높다고 판단해 현재는 제외.

### 2.3 SCADA 기반 파워커브

SCADA(터빈 10분단위 실측)로 물리 기반 파워커브를 만들어 보조 피처로 추가하는 실험:

| 실험 | Holdout Total Score |
|---|---:|
| Baseline (피처 없음) | 0.6241 |
| SCADA 보정 파워커브 (예보풍속→SCADA풍속 보정 후 커브 적용) | 0.6211 |
| 직접 파워커브 (예보풍속에 바로 커브 적용, SCADA 안 거침) | 0.6237 |

상관관계는 raw 풍속보다 증가(0.727→0.746)했지만 **실제 Holdout 성능 향상은 확인 안 됨**(오히려 둘 다 소폭 하락). 분석 결과: LightGBM이 이미 원시 풍속 정보만으로 파워커브 형태의 비선형 관계를 트리 분기로 학습하고 있어서, 미리 계산한 파워커브 피처는 새로운 정보를 추가하기보다 **기존 정보를 재표현한 수준**(+ 2단계 추정 과정의 노이즈)에 머문 것으로 판단. 현재 파이프라인에는 반영 안 함.

## 3. 현재까지 얻은 교훈

프로젝트 진행 과정에서 다음 패턴이 반복적으로 관찰됨:

- **상관관계 개선**
- **CV/Holdout 개선**
- **물리적으로 타당한 접근**

이 셋 다, **반드시 실제 리더보드 성능 향상으로 이어지지는 않았음.** Grid Aggregation 최적화, Isotonic Calibration, SCADA 파워커브 — 셋 다 일정 수준의 긍정적 신호(상관관계 또는 CV)가 있었지만 최종 성능 향상으로 이어지지 못함.

**추가로 확인된 것**: 다중 폴드 평균 CV와 단일 last-block holdout **둘 다** 학습기간(2022~2024) *안*의 데이터로만 검증하는 방법이라, 진짜 테스트 기간(2025, 완전한 미래 1년)과의 분포 차이를 못 잡아냄. 특히 FICR이 계단함수(6%/8% 경계)라서, 평균 오차가 아주 조금만 달라져도 그 경계를 넘나드는 시간이 많아지면 점수가 꽤 크게 흔들림 — 이게 CV/holdout이 반복적으로 실측과 반대로 나온 근본 원인으로 추정됨.

**→ 원칙: ±0.005 수준의 CV/holdout 개선은 노이즈로 취급. 앞으로는 단순한 피처 재가공보다 구조적 개선(새 정보원, 다른 오차 패턴의 모델, 대회 지표를 직접 겨냥한 손실함수)에 우선순위.**

## 4. 현재 검토 중인 후보

각 후보를 "새 정보인가? 기존 정보 재표현인가? 성공확률은?" 기준으로 먼저 걸러봄.

### 후보 1 — FICR을 고려한 학습 전략 ⭐ 가장 관심 있는 방향

현재 L1 Loss는 지표(NMAE 평균 + FICR 계단함수)와 완전히 일치하지 않음. 검토 중:
- Huber Loss / Quantile Loss — **이미 다중 폴드 CV로 시도해봄** (huber α=0.06: total 0.5718, α=0.08: 0.5778, quantile 0.5: 0.5790) — **L1(0.5790)과 동일하거나 오히려 못함.** 이 둘은 사실상 검토가 아니라 이미 기각된 후보임(단, 이건 다중 폴드 CV 기준이라 실측 재확인은 안 함).
- **FICR 근사 손실함수(6%/8% 밴드를 직접 겨냥한 커스텀 objective)** — 아직 아무도 안 만들어봄. 기존 L1/L2로는 원천적으로 표현 못 하는 불연속 보상구조를 직접 겨냥하는 유일한 "진짜 새로운 정보(=새로운 학습 신호)" 후보. 구현 비용은 있지만(gradient/hessian 설계 필요) 이론적 근거가 제일 강함 — FICR(0.35)이 1-NMAE(0.865)보다 훨씬 낮은 게 실측으로 확인된 진짜 문제이기 때문.

### 후보 2 — 규제된 Calibration

기존 Isotonic은 자유도가 높아 과적합됐을 가능성. Binned Calibration, Piecewise Linear Calibration처럼 더 단순한 형태 검토 중 — 실패 원인(자유도 과다)을 직접 겨냥한 재시도라 완전 배제할 근거는 약함. 단, 반드시 holdout 개선폭이 노이즈 기준(0.01+)을 넘을 때만 진행.

### 후보 3 — 그룹 간 정보 공유

현재 3개 그룹(kpx_group_1/2/3) 완전 독립 학습. 그룹3(UNISON)은 라벨 이력이 1년 적어서 그룹1/2(VESTAS)의 정보를 일부 활용하는 구조 검토 중. **다만 제조사·사이트 특성 자체가 달라서(그룹3은 저CF 꼬리가 원래 더 두꺼움 — 데이터 양 문제가 아니라 사이트 차이) 전이가 오히려 해가 될 리스크도 있음.**

### 후보 4 — 앙상블(CatBoost, XGBoost 등)

**중요:** 이 정확히 같은 시도가 **이 프로젝트의 다른(기존) 파이프라인에서 이미 있었고, 뚜렷한 개선이 확인 안 됨**("반복되는 정체 패턴" — 커밋 로그에 기록됨). 따라서 이론적으론 유망한 후보(오차 패턴이 다른 모델 조합)지만, 현재 우선순위는 높지 않음. 재시도한다면 왜 이번엔 다를지(피처셋 차이 등) 먼저 설명 가능해야 함.

## 5. 회의에서 논의하고 싶은 내용

현재 방향은 확정된 결론이 아니라 지금까지의 실험 결과를 바탕으로 한 우선순위. 팀원들의 결과를 적극 참고하고 싶고, 특히:

- CatBoost, XGBoost 등 다른 모델 계열 결과
- 새로운 피처 엔지니어링 아이디어
- 앙상블 실험 결과
- FICR 개선 사례
- 다른 검증 전략(CV/holdout이 왜 실측과 어긋나는지, 더 나은 방법이 있는지)
- 현재 파이프라인이 놓치고 있는 데이터 신호

명확한 개선 근거가 확인되면 기존 방향에 얽매이지 않고 적극 반영할 예정.

## 6. 결론

**LightGBM + L1 Objective**가 지금까지 실측으로 확정된 가장 안정적인 베이스라인(3차 제출, Total 0.6059).

단순한 피처 재가공(그리드 축소, calibration, SCADA 파워커브)은 상관관계·CV상으로는 그럴듯해 보여도 반복적으로 실측에서 무효화됨. 앞으로는 다음과 같은 **구조적 개선**에 우선순위:

1. **FICR을 고려한 학습 전략** (커스텀 손실함수 — 가장 유망, 아직 미시도)
2. **과적합을 줄인 Calibration** (binned/piecewise linear)
3. **그룹 간 정보 공유** (그룹3 데이터 부족 대응)
4. **새로운 모델 계열** (단, 이 프로젝트에서 이미 한 번 실패 기록 있어 우선순위 하향)

향후 실험 결과와 팀원 연구를 종합해 우선순위 계속 갱신 예정.
